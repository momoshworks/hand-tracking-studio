# 🖐️ Hand Tracking AI Studio (استوديو تتبع اليد الذكي)

نظام متكامل وشامل لتتبع حركة اليد في الوقت الفعلي (Real-Time Hand Tracking) يجمع **الأربعة أوضاع الرئيسية في منصة واحدة موحدة**:

1. **كاشف الإيماءات والأصابع ولغة الإشارة (Gestures & Finger Counter)**
2. **الفأرة الافتراضية والتحكم بالكمبيوتر (Virtual Mouse Controller)**
3. **لوحة الرسم والتوقيع في الهواء (Air Canvas / Virtual Painter)**
4. **التحكم بالصوت عن بُعد (Volume Gesture Controller)**

يحتوي المشروع على طريقتين للتشغيل:
- **تطبيق سطح مكتب سريع ومباشر (High-Performance Desktop GUI)** عبر OpenCV و HUD سيبراني عصري.
- **لوحة تحكم ويب تفاعلية (Full Web Dashboard)** مبنية بـ FastAPI + WebSockets + تصميم زجاجي عصري (Glassmorphism).

---

## 🌟 مميزات الأوضاع الأربعة

### 1️⃣ كاشف الإيماءات وعدّ الأصابع (Mode 1: Gestures & Counter)
* كشف فوري لـ 21 نقطة تشريحية في اليد بدقة ثلاثية الأبعاد (X, Y, Z).
* عدّ الأصابع المرفوعة (0 إلى 5) بدقة مع إشارات ملونة على كل طرف إصبع.
* التعرف التلقائي على إيماءات اليد الشهيرة باللغتين العربية والإنجليزية:
  * ✋ كف مفتوح (Open Palm)
  * ✊ قبضة مغلقة (Fist)
  * 👉 سبابة / إشارة (Pointing)
  * ✌️ إشارة النصر (Peace / Victory)
  * 🤏 قرص / تحديد (Pinch)
  * 👌 تمام / موافق (OK Sign)
  * 👍 إعجاب (Thumbs Up) / 👎 عدم إعجاب
  * 🤘 روك (Rock On) / 🤟 إشارة الحب (Love Sign)

### 2️⃣ الفأرة الافتراضية (Mode 2: Virtual Mouse)
* تحريك مؤشر الماوس بدقة عالية وسلاسة بفضل فلتر التنعيم الأسي (EMA Smoothing).
* منطقة تفاعلية محددة (Active Margin) تمنحك وصولاً لكامل الشاشة بسهولة.
* **النقر الأيسر (Left Click):** قرص السبابة مع الإبهام (Pinch).
* **النقر الأيمن (Right Click):** قرص الإصبع الأوسط مع الإبهام.
* **التمرير الرأسي (Scroll):** رفع السبابة والوسطى معاً وتحريكهما لأعلى أو لأسفل.
* **مفتاح أمان (Safety Toggle):** مفتاح تعطيل/تفعيل سريع لمنع الحركة غير المقصودة.

### 3️⃣ لوحة الرسم في الهواء (Mode 3: Air Canvas)
* شريط ألوان علوي متفاعل يضم ألوان النيون (Cyan, Magenta, Green, Yellow, White, Eraser).
* **وضع التحرك واختيار الألوان (Selection Mode):** ارفع السبابة والوسطى معاً للتنقل فوق الألوان أو التحرك بدون رسم.
* **وضع الرسم (Drawing Mode):** ارفع السبابة فقط للرسم الحر بخطوط ناعمة ومضادة للتسنن.
* إمكانية مسح اللوحة بالكامل فوراً أو حفظ الرسم كصورة PNG عالية الجودة.

### 4️⃣ التحكم بالصوت (Mode 4: Volume Controller)
* قياس المسافة بين الإبهام والسبابة في الهواء (25px إلى 180px).
* تحويل المسافة إلى مقياس نسبي من 0% (كتم) إلى 100% (الحد الأقصى).
* مؤشر عمودي وأفقي ديناميكي مع رسم توضيحي للمسافة.

## 🚀 طريقة التشغيل السريعة

### 1. تشغيل لوحة تحكم الويب (Web Dashboard):
انقر نقراً مزدوجاً على الملف:
```bash
run_web.bat
```
أو عبر PowerShell:
```powershell
.\run_web.ps1
```
سيبدأ الخادم ويفتح المتصفح تلقائياً على الرابط: `http://localhost:8050`

---

### 2. تشغيل تطبيق سطح المكتب (Desktop Mode):
انقر نقراً مزدوجاً على:
```bash
run_desktop.bat
```
أو عبر PowerShell:
```powershell
.\run_desktop.ps1
```

#### اختصارات لوحة المفاتيح أثناء التشغيل:
* `1`: تفعيل وضع الإيماءات والعدّ.
* `2`: تفعيل وضع الفأرة الافتراضية.
* `3`: تفعيل وضع لوحة الرسم بالهواء.
* `4`: تفعيل وضع التحكم بالصوت.
* `M`: تفعيل / إيقاف الفأرة الافتراضية (Safety Toggle).
* `C`: مسح لوحة الرسم (Clear Canvas).
* `S`: حفظ الرسمة الحالية في مجلد `drawings/`.
* `Q` أو `Esc`: الخروج وإغلاق البرنامج.

```
hand-tracking-studio/

├── core/                       # المحركات الأساسية المستقلة
│   ├── detector.py             # محرك كشف الـ 21 نقطة تشريحية عبر MediaPipe
│   ├── gestures.py             # محلل الإيماءات وحالات الأصابع

│   └── audio_ctrl.py           # حساس المسافة ومستوى الصوت
│
├── static/                     # الواجهة الأمامية للويب
│   ├── css/style.css           # تصميم زجاجي عصري Glassmorphism
│   └── js/app.js               # إدارة اتصالات WebSocket والـ HUD
│
├── templates/
│   └── index.html              # لوحة التحكم التفاعلية
│
├── desktop_app.py              # المشغل المباشر لسطح المكتب (OpenCV GUI)
├── main.py                     # خادم الويب (FastAPI + WebSocket + Stream)
├── requirements.txt            # المكتبات والاعتماديات
├── run_web.bat / .ps1          # سكريبت تشغيل الويب
└── run_desktop.bat / .ps1      # سكريبت تشغيل سطح المكتب
```
